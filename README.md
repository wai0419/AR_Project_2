# AR_Project_2

> 掃描利樂包，瞬間變身魔法鬼屋！
> 一支結合實體包裝與擴增實境的行銷互動專案。

**製作單位**：互動細胞 Visual Fun

---

## 專案簡介

這是我在公司參與製作的萬聖節主題 AR 行銷專案。使用者透過手機或平板鏡頭掃描實體的利樂包包裝，AR 引擎即時辨識包裝圖案作為追蹤標記，並在畫面上疊加一棟精緻的 3D 鬼屋模型，搭配動態燈光、氛圍粒子特效與行走的南瓜怪角色動畫，將平凡的包裝盒轉化為一場沉浸式的萬聖節魔法體驗。

## 我負責的部分

在這個專案中，我主要負責 **互動機制程式設計** 與 **美術特效整合** 兩大部分：

### 互動機制程式設計
- AR 影像標記辨識與即時追蹤邏輯，確保 3D 場景能穩定貼合在利樂包表面，並隨包裝的角度、距離變化即時調整模型的位置、旋轉與縮放
- 場景載入與狀態管理，控制鬼屋場景的觸發時機、進場動畫節奏
- 角色行為邏輯（南瓜怪等生物於場景中的路徑移動、動畫切換）

### 美術特效整合
- 將美術團隊產出的 3D 鬼屋模型、材質與動畫整合進即時渲染引擎
- 燈光效果調校（窗戶透光、南瓜燈籠光暈、串燈裝飾閃爍等），營造夜晚陰森又溫馨的萬聖節氛圍
- 粒子系統特效整合（屋頂魔法星塵、環境飄浮光點），強化「包裝盒變身魔法建築」的視覺衝擊力與神秘感
- 即時渲染畫面與真實環境光影的協調調整，讓虛擬物件盡量融合於實拍畫面中

## 技術亮點

- **AR 圖像追蹤**：以利樂包本身的印刷圖案作為追蹤目標，不需額外增加實體標記物，維持產品包裝的完整性與行銷質感
- **即時 3D 渲染**：鬼屋模型具備多層次細節（門廊、窗戶、屋頂、庭院裝飾），並支援即時光影變化
- **動態粒子特效**：模擬魔法光點飄散效果，強化「魔法變身」的敘事張力
- **角色動畫整合**：場景中加入會走動的萬聖節角色，提升互動趣味與畫面豐富度
- **行動裝置即時運行**：整體效果於平板／手機上即時運算與渲染，無需額外安裝或後製

## 應用情境

此類 AR 互動特效可應用於：
- 產品包裝行銷活動（掃碼即可觸發專屬節慶內容）
- 零售通路的互動展示裝置
- 社群媒體宣傳素材（如本次 Demo 影片即用於短影音宣傳）
